# Signal Repeat v0.1.0

Signal Repeat v0.1.0 is the first MVP release of the focused repetition plugin
for RemNote.

## Highlights

- Start a short repeat session from selected text, a revealed forward or reverse
  flashcard answer, the focused Rem, or Option/Alt+M.
- Choose a 10, 15, 20, or 30-second duration and optionally show progress and
  close hints.
- End early with Escape or let the session close automatically with focus
  restoration.
- Keep RemNote in control: Signal Repeat does not edit learning content, rate
  cards, advance queues, or change scheduling data.

## Privacy

Learning content stays inside the RemNote plugin environment. Signal Repeat has
no external network path, does not log or persist learning content, and stores
only plugin preferences through RemNote.

## Known limitation

Cloze-answer extraction is not included in v0.1.0. When no safe target can be
resolved, Signal Repeat shows a fixed notification and opens no popup.

## Installation

Install the published plugin from **Settings → Plugins** in RemNote. The attached
`PluginZip.zip` is the exact release artifact for verification and distribution.
