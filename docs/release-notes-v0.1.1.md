# Signal Repeat v0.1.1

Signal Repeat v0.1.1 is a presentation and release-readiness update for the
focused repetition plugin for RemNote.

## What's new

- Adds a dedicated Signal Repeat logo for RemNote plugin listings and installed
  plugin surfaces.
- Adds a step-by-step RemNote public-listing checklist.
- Adds the implementation handoff for the planned v0.2.0 mobile work.

## Behavior

The focused-repeat behavior is unchanged from v0.1.0. Signal Repeat supports
selected text, revealed forward and reverse flashcard answers, the focused Rem,
and Option/Alt+M on RemNote Web and Desktop.

## Privacy

Learning content stays inside the RemNote plugin environment. Signal Repeat has
no external network path, does not log or persist learning content, and stores
only plugin preferences through RemNote.

## Known limitations

- Mobile activation remains disabled pending real-device SDK verification.
- Cloze-answer extraction is not included. When no safe target can be resolved,
  Signal Repeat shows a fixed notification and opens no popup.

## Installation

Install the published plugin from **Settings → Plugins** in RemNote. The attached
`signal-repeat-remnote-v0.1.1.zip` is the exact release artifact for verification
and distribution.
