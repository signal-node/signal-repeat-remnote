# Code of conduct

## Our standard

Contributors must communicate respectfully, welcome constructive feedback, and
focus discussion on improving Signal Repeat. Harassment, discrimination,
personal attacks, deliberate disruption, and publication of another person's
private information are unacceptable.

## Project spaces

This standard applies to repository issues, pull requests, discussions, and
other spaces where someone represents the project.

## Enforcement

Report conduct concerns privately to the repository owner. Maintainers may
edit or remove contributions and may temporarily or permanently restrict
participation when behavior violates this standard. Reports will be handled as
confidentially as practical.
